# Process
In this folder, we will document our design process.

We will be using the "[process](https://github.com/pippinbarr/itisasifyouweredoingwork/tree/master/process)" method developped by [Pippin Barr](https://github.com/pippinbarr/) for his project [It Is As If You Were Doing Work](https://github.com/pippinbarr/itisasifyouweredoingwork). For more information on this method, cf. our first class tutorial from [2026-10-05](./2026-10-05/).
