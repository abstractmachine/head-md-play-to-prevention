# Game Design Document
Create a Game Design Document. You can work with a robot — context is everything — or ignore the existence of robots; it is up to you.

## Gameplay
The goal for today is to identify the core gameplay mechanics.

## One Pager
Create a single-page document that describes the core concept and mechanics of your experience.

## As if…
What existing cyberspace(s) does this project simulate? Explore the [As if…](./as-if.md) exercise, and write out here the core components of your simulator. How does this simulator *fictionalize* this cyberspace?

## Ingredients
Here are some ingredients that you should put inside of your Game Design Document:

- Title
- Authors
- One-Liner
- Pitch
- Prevention
    - What is the dilemma
    - What is learned?
- Core Mechanics
- Story & Setting
- Unique Bits
