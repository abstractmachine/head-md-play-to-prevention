# From Play to Prevention
## Designing a library of micro-playful experiences for cyberbullying prevention

This workshop is part of an Innosuisse-funded research project developed in collaboration with the [Master Media Design](https://head.hesge.ch/en/programs-research/master-arts-media-design) at [HEAD – Genève](https://head.hesge.ch) ([HES-SO](https://hesge.ch)) and [Arpège](https://arpegespt.ch). The aim is to create a platform of playable experiences for cyberbullying prevention among young people aged 12–16. This workshop addresses the first stage of this project.
